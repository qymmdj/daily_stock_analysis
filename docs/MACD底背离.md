# 黄金坑MACD底背离选股
## 算法
1、从最新日K线开始往前查找，找到连续下跌超过3天但小于5天且跌幅高于5%但小于10%的日期A
2、从日期A往后查找，找到第一个收阳线的日期A1,计算A1到最新日期K线的累计涨涨跌幅在-5%到5%之间
3、在从日期A往前查找，找到第一个收阳线的日期B
4、在从日期B往前查找，找到连续下跌超过3天小于5天且跌幅高于15%小于25%的日期C
5、从日期C往后查找，找到第一个收阳线的日期C1,计算C1到B时间段日K线的累计涨跌幅跌幅在-5%到5%之间
6、计算两个下跌A1到A ，C1到C区域的MACD，A处的值明显大于C处的值(如1.5倍）
7、从C继续往前查找首次出现阳线的日期C2，从C2开始往前统计（250天内）出现涨幅大于9%的次数大于等于3次


##注意：
1、往前查找表示查找更早日期的K线数据
2、往后查找表示查找最新日期的K线数据

## 输入
### 第一种模式
1、股票代码
2、结束日期，可选，默认最新日期
3、K线天数默认250天

### 第二种模式
1、stock_limitup.csv文件路径作为输入，文件格式如下:
第一行用来表示各个字段的含义
从第二行开始为股票数据
```text
涨停次数 股票代码  股票中文名称 关联板块名称
48	000981.SZ	山子股份	新能源汽车
```

## 输出
### 格式
markdown 格式，包含以下字段：
1、股票代码
2、股票中文名称
3、关联板块名称
4、MACD A值（下跌阶段A的MACD最小值）
5、MACD C值（下跌阶段C的MACD最小值）
6、下跌阶段A时间范围
7、下跌阶段C时间范围
8、置信度

### 存储
存入到gitee的stockdb的xg目录，文件名格式为：
`MACD底背离选股_日期.md`

其中日期格式为：YYYY-MM-DD
