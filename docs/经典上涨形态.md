## 一、基于日K线数据的4种经典上涨形态识别逻辑

| 形态名称                | 识别逻辑（基于均线、量价、K线特征）                                                           | 关键参数            |
| :------------------ | :--------------------------------------------------------------------------- | :-------------- |
| **1. 均线多头排列**       | 当前MA5 > MA10 > MA20 > MA60，且股价在MA5之上；MA5、MA10、MA20均线呈发散向上趋势（斜率>0）            | 均线周期：5/10/20/60 |
| **2. 上升通道（旗形）**     | 过去N日（如20日）内，每个低点都高于前一个低点，每个高点也高于前一个高点；且回调时成交量萎缩，上涨时成交量温和放大                   | 低点抬高、高点抬高、量价配合  |
| **3. 首次回踩重要均线（买点）** | 股价经历一波上涨（如20日内涨幅>15%），随后缩量回调至MA20或MA60附近，获得支撑（收盘价≥均线且下影线较长），且回调期间成交量明显低于上涨期间 | 回调缩量、均线支撑、下影线   |
| **4. 圆弧底/杯柄形态**     | 过去60日内，股价先缓慢下跌后缓慢上涨，形成一个U型底部；右侧成交量较左侧明显放大；当前股价已突破底部区域的高点（或接近突破）              | 底部对称、右侧放量、突破颈线  |

> **注意**：以上逻辑需要你传入足够的历史K线数据（至少120个交易日）才能准确识别。

## 二、股价强度分析（相对强弱）

股价强度用于判断个股是否跑赢大盘或板块。由于你没有提供大盘指数数据，我设计一个**基于个股自身趋势的强度分析**：

| 强度指标      | 计算方法                       | 说明                    |
| :-------- | :------------------------- | :-------------------- |
| **短期强度**  | 最近5日涨跌幅 vs 最近20日涨跌幅        | 若短期涨幅大于中期涨幅，说明加速      |
| **中期强度**  | 最近20日涨跌幅 vs 最近60日涨跌幅       | 若中期涨幅大于长期，说明处于上升趋势    |
| **量价配合度** | 最近20日上涨日平均成交量 / 下跌日平均成交量   | >1.2表示量价健康            |
| **均线乖离率** | (当前价 - MA20) / MA20 × 100% | 0%\~8%为正常上升趋势，>15%为超买 |
